# Changelog

## 0.1.1

- Reworked MoneyAction as a global-first app foundation.
- Added Korean, English, Japanese, Spanish and Brazilian Portuguese UI packs.
- Added market profiles for KR, US, CA, GB, AU, JP, MX, ES, BR and Global/Other.
- Added locale-aware currencies and starter target presets.
- Added stable IDs for skills, interests and mission categories.
- Added v0.1.0 local-storage migration.
- Localized demo planning flow for all 5 languages.
- Added market-aware Gemini prompt and response validation.
- Changed daily AI quota date calculation from UTC to user timezone.
- Added AI request timeout/error handling.
- Added GitHub Actions debug APK build workflow.
- Changed default global app/manifest name to MoneyAction.
